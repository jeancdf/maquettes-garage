# Maquettes — garages et carrossiers

Maquettes de sites vitrines à présenter aux prospects : https://jeancdf.github.io/maquettes-garage/

- `index.html` : les modèles, avec un aperçu et un lien vers chaque page.
- `comparer.html` : bascule rapide entre les formules (boutons, touches 1 à 5, flèches ←/→, ancres `#essentiel`, `#complet`, `#duval`…).

| Page | Modèle |
| --- | --- |
| `essentiel.html` | Garage Moreau — Formule Essentiel |
| `complet.html` | Garage Moreau — Formule Complet |
| `duval.html` | Carrosserie Duval — carrosserie et peinture, Lille |
| `atelier1965.html` | Atelier 1965 — voitures anciennes, Tours |
| `ampere.html` | Garage Ampère — hybride et électrique, Toulouse |

Essentiel (690 € HT) et Complet (1 190 € HT) utilisent le même établissement fictif pour comparer les gammes. Sur mesure : 1 990 à 2 990 € HT.

Établissements fictifs : tarifs et cartes indicatifs, coordonnées entre crochets à personnaliser.
Photographies : [Unsplash](https://unsplash.com) (licence Unsplash), utilisées à titre d’illustration.
